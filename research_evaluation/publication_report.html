1. Executive Summary

This report delivers a rigorous, empirical evaluation of the existing video summarization system for publication in an IEEE-style peer-reviewed venue. Rather than assuming the architecture conformed to proposed research concepts, an exhaustive code and checkpoint audit was conducted, missing experimental harnesses were developed, and eight reproducible experiments were executed on CPU hardware.

Key Empirical Findings:

1. Architectural Divergence: The operational pipeline does not employ GoogLeNet, VASNet, Kernel Temporal Segmentation (KTS), Qwen2.5-0.5B-Instruct, or SmolVLM-256M. Instead, it implements a custom 2-layer Bidirectional LSTM (BiLSTM) fusion model (1.005M parameters) with ResNet-18 (512-dim visual features), SentenceTransformers all-MiniLM-L6-v2 (384-dim text features), fixed 180-second chunking, and T5-small (60M parameters) for transcript summarization. 2. Multimodality Boundary: The framework is multimodal only during segment importance scoring. Final abstractive text generation is strictly unimodal—T5-small receives speech transcript tokens and receives zero visual features or visual tokens. 3. Training Data Provenance: The 75 benchmark entries in datasets/processed_dataset.json were generated synthetically using normalized Gaussian random vectors with temporal bias heuristics. Neither raw SumMe/TVSum frames nor Apple's LVSum dataset were decoded during training. 4. Predictive Performance on Test Data: On the held-out test split (12 videos, 249 temporal segments), Checkpoint B achieves an MSE of 0.0073 and an apparent F1-score of 0.9939 at threshold 0.5. However, linear correlation is near zero (Pearson r = -0.0506, p = 0.4264, Spearman \rho = -0.0551). This reveals that the low MSE is an artifact of narrow target clustering (mean 0.875, std 0.043), rather than meaningful saliency ranking. 5. Ablation Findings: Ablation proves the multimodal architecture relies on feature co-presence. Zeroing out text degrades MSE by 4.6\times (0.0073 \rightarrow 0.0335), zeroing out visual inputs degrades MSE by 5.8\times (0.0073 \rightarrow 0.0423), and removing both causes catastrophic divergence (MSE 0.7588). 6. Computational Efficiency: On an AMD Ryzen 5 5600H CPU, segment scoring requires just 6.00 ms per sequence. The end-to-end pipeline processes a 30-minute video in 11.75 seconds (Real-Time Factor, \text{RTF} = 0.0065), demonstrating exceptional execution throughput for resource-constrained deployments. ---

2.1 The Multimodal Boundary

A primary claim in multimodal research is that visual and acoustic modalities jointly condition summary generation. Inspection of backend/services/summarizer.py (lines 49–96 and 109–158) confirms: - Chunks receive visual descriptions from generate_visual_description(), but this function returns a static string: "Visual frame showing lecture slide or video scene activity." - In generate_chunk_summary(), only chunk.get("transcript", "") is fed into T5-small. - In generate_final_summary(), the prompt combines previously generated textual chunk summaries. Formal Clarification for Publication: The framework is multimodally conditioned at the selection stage (visual features inform which temporal chunks are retained), but unimodal at the abstractive generation stage (the generative text model processes transcripts exclusively). ---

3. Dataset Audit and Verification

3.1 Status of LVSum Benchmark

The research plan specified fine-tuning VASNet on the LVSum dataset. An audit across all directories, configuration files, and git history confirms: - No LVSum video files, metadata annotations, or feature caches exist in the project repository. - training/download_dataset.py references a Kaggle dataset (python16/summe-videos-and-tvsum-videos/versions/1), not LVSum.

3.2 Verification of Training Data (datasets/processed_dataset.json)

The primary training dataset consists of 75 videos totaling 1,506 temporal segments. Statistical inspection confirms this data was generated synthetically by training/preprocess.py: - Features were generated using np.random.randn(n, 512) and np.random.randn(n, 384) with L_2 unit normalization. - Ground-truth importance scores were calculated from feature variance plus temporal bias:
\text{Score} = \text{clip}\left(0.30 + 0.35 \frac{\sigma_v}{\max(\sigma_v)} + 0.30 \frac{\sum |t_{:20}|}{\max(\sum |t_{:20}|)} + |\text{bias}| + \epsilon, 0.10, 0.95\right)
- Consequently, the ground-truth scores have an artificial mean of 0.8750 and standard deviation of 0.0435 (see [dataset_audit.csv](file:///c:/Users/ravindra_007/OneDrive/Desktop/ai%20prioritizer/video-summarizer/research_evaluation/dataset_audit.csv)).

3.3 Partitioning Protocol and Data Leakage

The data split in datasets/data_split.json establishes a strict video-level partition: - Training Set: 52 videos (1,018 segments, 67.6%) - Validation Set: 11 videos (239 segments, 15.9%) - Test Set: 12 videos (249 segments, 16.5%) - Partition Verification: \text{Train} \cap \text{Val} = \emptyset, \text{Train} \cap \text{Test} = \emptyset, \text{Val} \cap \text{Test} = \emptyset. Segment-level leakage is zero. ---

10. Threats to Validity and Failure Modes

1. Synthetic Training Artifacts: The model was trained on synthetic Gaussian vectors rather than real benchmark frames. This explains the disconnect between training correlation (r = +0.30) and test correlation (r = -0.05). 2. Score-Scaling Heuristic: In importance_model.py (lines 120–131), when prediction variance drops below 0.15, the application artificially recalculates scores between 0.42 and 0.96 using transcript word count and frame standard deviation:
\text{Score}_{\text{scaled}} = \min\left(0.96, \max\left(0.42, 0.50 + 0.35 \frac{i}{N-1} + \Delta_{\text{score}} + \frac{W_t}{200} + 2\sigma_v\right)\right)
This heuristic masks the model's low variance in production, but represents an engineering workaround rather than a learned capability. 3. Coarse Temporal Granularity: Fixed 180-second chunks lack boundary awareness, occasionally grouping distinct topics into a single segment. ---

11. Concrete Recommendations for Future Research

1. Execute Real Feature Extraction: Run python -m training.feature_extraction on real SumMe and TVSum videos (or LVSum) using Kaggle credentials to replace synthetic data with authentic ImageNet and human annotations. 2. Implement KTS or Semantic Scene Boundaries: Replace the rigid 180-second chunking with Kernel Temporal Segmentation or optical flow scene-change detection. 3. Transition to Cross-Attention Summarization: Pass visual features directly to the LLM (e.g., using SmolVLM or Qwen2-VL) so that visual demonstrations directly shape the generated text summary. 4. Adopt Standard Evaluation Protocols: Evaluate using the knapsack 15% video budget and 5-fold cross-validation with harmonic mean F1 against human summary selections.
